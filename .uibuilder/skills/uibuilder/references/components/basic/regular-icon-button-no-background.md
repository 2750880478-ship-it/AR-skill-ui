# 图标按钮/常规按钮-无底色

## Pixso 基本信息

- 组件集名称：`图标按钮/常规按钮-无底色`
- Component Set ID：`613:115653`
- 组件集尺寸：196 × 64
- 组件类型：无底色常规图标操作
- Variant 属性：`属性 1`
- 组件实例尺寸：24 × 24
- 内部图标实例名称：`常规操作`
- 内部图标尺寸：`fill_container` × `fill_container`
- 适用尺寸：1920、1280 共用；组件本身没有分辨率 Variant。

> 本文中的名称、Variant 属性和值均保持 Pixso 当前命名。`属性 1`不得被改写为“状态”等其他名称。

## 使用规则

- 用于工具栏、标题栏、卡片操作区、面板操作区等位置的常规图标操作。
- 适合操作层级较低、图标语义明确且不需要持续选中反馈的动作。
- 不用于 AR 主画面的高优先级主要操作；主要操作应使用 `图标按钮/home主按钮`。
- 不用于需要持续表达“功能已开启”或“当前已选中”的模式切换，因为本组件没有选中状态。
- 图标必须来自组件内部使用的 `常规操作`图标资源，不自行绘制、替换为图片或使用近似图标。
- 组件没有可见背景容器，不得通过实例覆盖为其增加背景。需要带底色的常规图标操作时，应选择对应的带底色组件。
- 1920和1280均保持24 × 24实例尺寸；适配通过父级操作区的排列、间距、隐藏规则或收纳方式完成。

## Variant与状态

组件只使用 `属性 1`表达交互状态：

| `属性 1`的Pixso值 | 使用条件 | 交互说明 | Variant GUID |
|---|---|---|---|
| `nor` | 操作可用，当前没有指针交互 | 默认可操作状态 | `187:1235` |
| `hov` | 指针悬停在可用图标按钮上 | 指针移出后恢复 `nor` | `187:190` |
| `pre` | 指针按下，操作尚未释放 | 释放后执行动作并恢复 `nor`，或根据业务条件进入 `dis` | `187:194` |
| `dis` | 操作暂不可用 | 不响应点击；条件恢复后切回 `nor` | `358:83053` |

Pixso当前没有 `sel`、`sel-hov`、`foc`、`loading`或报警状态，不得自行补充。

## 状态转换

- `nor` → `hov`：指针进入可用按钮。
- `hov` → `nor`：指针离开。
- `hov` → `pre`：用户按下按钮。
- `pre` → `nor`：用户释放按钮且操作仍可用。
- 任意可用状态 → `dis`：业务条件变化导致操作不可用。
- `dis` → `nor`：不可用条件解除。

该组件用于一次性动作，不保持选中状态。需要持续选中反馈时，必须选择含有选中Variant的其他组件。

## 已读取结构

- `nor`、`hov`、`pre`、`dis`四个Variant均为24 × 24。
- 每个Variant内部包含一个名为 `常规操作`的图标实例。
- 内部图标使用 `fill_container`填充组件实例范围。
- 状态变化由Variant表达，不通过手工改变图标颜色或透明度实现。

## 允许修改

- 在 `nor`、`hov`、`pre`、`dis`之间切换。
- 使用组件开放的实例替换能力，将内部 `常规操作`切换为已有图标资源。
- 调整实例在父级工具栏、标题栏或操作组中的位置与外部间距。
- 根据对应业务动作配置点击行为和Tooltip。

## 禁止修改

- 禁止重命名 `属性 1`或其Variant值。
- 禁止新增 `sel`、`sel-hov`、`foc`、`loading`等不存在的状态。
- 禁止用本组件表达持续选中、模式开启或报警状态。
- 禁止为组件手工增加底色、描边、圆角、阴影或外发光。
- 禁止修改24 × 24实例尺寸或内部图标的填充关系。
- 禁止拆散、解绑、扁平化实例，或增删、复制、重排内部图层。
- 禁止手工覆盖图标颜色、透明度和变量绑定。
- 禁止使用基础图层、图片、截图或HTML/CSS仿制本组件。

## 选择与实例化

1. 使用 `read_components`读取组件集 `图标按钮/常规按钮-无底色`。
2. 使用 `query_nodes`查询 Component Set ID `613:115653`，并按 `属性 1=<值>`解析目标Variant。
3. 使用查询返回的目标Variant `guid`实例化，不把 Component Set ID直接作为实例 `ref`。
4. 写入后检查组件关联、内部图标、Variant和尺寸是否保持正确。
