# 图标按钮/home主按钮

## Pixso 基本信息

- 组件集名称：`图标按钮/home主按钮`
- Component Set ID：`414:51695`
- 组件集尺寸：360 × 88
- 组件类型：AR 主画面主要图标操作
- Variant 属性：`状态`、`属性 3`
- `属性 3` 当前值：`带底色`
- 组件实例尺寸：48 × 48
- 内部图标实例名称：`home主要-40`
- 内部图标显示尺寸：32 × 32
- 适用尺寸：1920、1280 共用；组件本身没有分辨率 Variant。

> 本文保留 Pixso 当前的组件、属性和值命名。`属性 3` 虽然不是语义化名称，但不得在使用时自行重命名。

## 使用规则

- 用于 AR 主画面中需要持续可见、操作优先级较高的图标操作。
- 适用于主画面操作区，不用于表单提交、弹窗确认或普通列表行操作；这些场景应选择对应的按钮组件。
- 同一操作组中的同类主要操作统一使用本组件，不混入尺寸和底色体系不同的普通图标按钮。
- 图标必须使用组件内部允许替换的现有图标资源，不自行绘制近似图标。
- 组件必须使用真实实例并切换既有 Variant，不得用圆形/矩形背景加图标重新拼装。
- 1920 与 1280 页面均保持48 × 48实例尺寸；通过调整外部操作组的排列、间距或收纳方式适配，不缩放组件内部结构。

## Variant

### `属性 3`

| Pixso 值 | 使用说明 |
|---|---|
| `带底色` | 当前组件集唯一存在的底色形式，所有状态都使用此值 |

不得写入 `无底色` 等当前组件集中不存在的值。需要无底色图标操作时，应改用其他已批准组件集。

### `状态`

| Pixso 值 | 使用条件 | 交互说明 |
|---|---|---|
| `nor` | 操作可用，当前未悬停、未选中 | 默认状态 |
| `hov` | 指针悬停在未选中的可用按钮上 | 指针移出后恢复 `nor` |
| `sel` | 对应功能已开启、当前模式已激活或当前项已选中 | 在功能保持开启期间持续显示 |
| `sel-hov` | 指针悬停在已选中的按钮上 | 指针移出后恢复 `sel` |
| `dis` | 操作因业务条件不可用 | 不响应点击；条件恢复后切换为 `nor`，或按当前业务状态切换为 `sel` |

## 状态转换

- `nor` → `hov`：指针进入未选中且可用的按钮。
- `hov` → `nor`：指针离开，且功能未被激活。
- `hov` → `sel`：用户触发操作且对应功能进入激活/选中状态。
- `sel` → `sel-hov`：指针进入已选中的按钮。
- `sel-hov` → `sel`：指针离开，功能仍保持激活。
- `sel`或`sel-hov` → `nor`：用户关闭功能或退出当前模式。
- 任意可用状态 → `dis`：业务条件变化导致操作不可用。

当前组件没有独立的按下状态。不得用 `pre`、`点击` 或其他名称补造按下 Variant。

## 已读取结构

- 所有 Variant 的实例尺寸均为48 × 48。
- 每个 Variant 内包含一个名为 `home主要-40` 的图标实例。
- `home主要-40` 在该组件中的显示尺寸为32 × 32。
- 状态变化由组件 Variant 表达，不通过手工修改背景或图标颜色实现。

## 允许修改

- 在 `nor`、`hov`、`sel`、`sel-hov`、`dis` 之间切换。
- 使用组件允许的方式替换 `home主要-40` 对应的现有图标类型。
- 调整实例在父级操作组中的顺序、位置和外部间距。
- 根据业务功能设置按钮的交互行为。

## 禁止修改

- 禁止重命名 `状态`、`属性 3` 或它们的值。
- 禁止添加 `pre`、`foc`、`loading` 等不存在的状态。
- 禁止把 `属性 3=带底色` 改造成无底色样式。
- 禁止修改实例的48 × 48尺寸和内部图标的32 × 32尺寸。
- 禁止拆散、解绑、扁平化组件实例，或增删、重排内部图层。
- 禁止手工覆盖背景、图标颜色、圆角、透明度、阴影和变量绑定。
- 禁止用基础图层、图片、截图或HTML/CSS仿制本组件。

## 选择与实例化

1. 使用 `read_components` 读取组件集 `图标按钮/home主按钮`。
2. 使用 `query_nodes` 查询 Component Set ID `414:51695`，并按 `状态=<值>, 属性 3=带底色` 解析目标 Variant。
3. 使用查询返回的目标 Variant `guid` 实例化，不把 Component Set ID 直接作为实例 `ref`。
4. 写入后检查组件关联、图标资源、状态及尺寸是否保持正确。
