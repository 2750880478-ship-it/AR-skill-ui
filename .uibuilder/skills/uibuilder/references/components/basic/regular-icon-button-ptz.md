# 图标按钮/常规按钮-ptz

## Pixso基本信息

- 组件集名称：`图标按钮/常规按钮-ptz`
- Component Set ID：`613:115724`
- 组件集尺寸：196 × 64
- 组件类型：PTZ常规图标操作
- Variant属性：`状态`
- 组件实例尺寸：24 × 24
- 内部图标实例名称：`常规操作`
- 内部图标尺寸：`fill_container` × `fill_container`
- 适用尺寸：1920、1280共用；组件本身没有分辨率Variant。

> 本文保留Pixso当前命名。`默认`、`悬停`使用中文，`foc`、`foc-hov`使用英文缩写，不得统一改写。

## 使用规则

- 用于PTZ功能的入口或PTZ模式状态切换。
- 适用于需要区分“未进入PTZ”和“已进入PTZ聚焦模式”的图标操作。
- 未进入PTZ模式时使用 `默认`或`悬停`；进入PTZ模式后使用 `foc`或`foc-hov`。
- 不用于普通的一次性图标操作。没有PTZ聚焦语义的操作应使用其他常规图标按钮。
- 不使用 `foc`表达键盘焦点、输入框焦点或一般选中；本组件中的 `foc`专指PTZ功能处于聚焦/激活状态。
- 图标必须使用组件内部的 `常规操作`实例和Pixso现有资源，不自行绘制PTZ图标。
- 1920和1280均保持24 × 24实例尺寸，仅调整父级操作区的布局与收纳。

## Variant与状态

| `状态`的Pixso值 | 使用条件 | 交互说明 | Variant GUID |
|---|---|---|---|
| `默认` | PTZ功能可用但当前未进入PTZ模式，且指针未悬停 | PTZ入口的静止状态 | `613:115679` |
| `悬停` | 指针悬停在尚未激活的PTZ入口上 | 指针移出后恢复 `默认` | `613:115694` |
| `foc` | 已进入PTZ模式，指针未悬停在按钮上 | 持续表示PTZ处于聚焦/激活状态 | `613:115709` |
| `foc-hov` | 已进入PTZ模式，且指针悬停在按钮上 | 指针移出后恢复 `foc` | `187:198` |

Pixso当前没有 `pre`、`dis`、`sel`、`loading`或报警状态，不得自行补充。

## 状态转换

- `默认` → `悬停`：指针进入未激活的PTZ按钮。
- `悬停` → `默认`：指针离开且未进入PTZ模式。
- `悬停` → `foc`：用户触发PTZ入口并成功进入PTZ模式。
- `foc` → `foc-hov`：指针进入已激活的PTZ按钮。
- `foc-hov` → `foc`：指针离开，PTZ模式仍保持激活。
- `foc`或`foc-hov` → `默认`：用户退出PTZ模式或当前通道失去PTZ激活状态。

组件没有独立按下状态。鼠标按下时不得临时套用其他组件的 `pre`表现。

## 已读取结构

- `默认`、`悬停`、`foc`、`foc-hov`四个Variant均为24 × 24。
- 每个Variant内部包含一个名为 `常规操作`的图标实例。
- 内部图标使用 `fill_container`填充组件范围。
- PTZ激活及悬停反馈由组件Variant表达，不通过手工改变图标颜色、透明度或背景实现。

## 允许修改

- 在 `默认`、`悬停`、`foc`、`foc-hov`之间切换。
- 按组件开放能力使用与PTZ业务匹配的现有 `常规操作`图标资源。
- 调整组件实例在PTZ操作区或相机通道操作区中的外部位置和间距。
- 配置进入PTZ、退出PTZ及悬停提示交互。

## 禁止修改

- 禁止翻译、重命名或统一改写Variant值。
- 禁止添加 `pre`、`dis`、`sel`、`loading`等不存在的状态。
- 禁止将 `foc`用于非PTZ的一般选中或键盘焦点。
- 禁止使用本组件承载与PTZ无关的普通操作。
- 禁止修改24 × 24实例尺寸或内部图标填充关系。
- 禁止增加底色、描边、圆角、阴影或其他装饰。
- 禁止拆散、解绑、扁平化实例，或增删、复制、重排内部图层。
- 禁止手工覆盖图标颜色、透明度和变量绑定。
- 禁止使用基础图层、图片、截图或HTML/CSS仿制本组件。

## 选择与实例化

1. 使用 `read_components`读取组件集 `图标按钮/常规按钮-ptz`。
2. 使用 `query_nodes`查询Component Set ID `613:115724`，并按 `状态=<值>`解析目标Variant。
3. 使用查询返回的目标Variant `guid`实例化，不把Component Set ID直接作为实例 `ref`。
4. 写入后检查组件关联、PTZ业务状态、内部图标和尺寸是否正确。
