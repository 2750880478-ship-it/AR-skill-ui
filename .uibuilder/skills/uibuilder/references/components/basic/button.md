# 按钮

## Pixso 基本信息

- 组件集名称：`按钮`
- Component Set ID：`221:180916`
- 组件集尺寸：144 × 472
- 组件类型：基础操作控件
- Variant 属性：`类型`、`状态`
- 适用尺寸：1920、1280 共用；组件本身没有分辨率 Variant，由页面外部布局负责适配。

> 本文中的组件名称、Variant 属性和值均保持 Pixso 当前命名，不翻译、不改写，也不补充 Pixso 中不存在的状态。

## 使用规则

- `一级按钮`：用于当前区域中优先级最高、推动主要任务完成的操作。同一操作区避免同时出现多个一级按钮。
- `二级按钮`：用于次要操作、取消类操作，或与一级按钮并列但优先级较低的操作。
- `三级图文按钮`：用于弱层级的图标加文字操作，不替代一级或二级业务提交操作。
- 必须使用该组件集的真实实例并切换已有 Variant，不得用矩形、文字和图标重新拼装按钮。
- 按钮文案必须描述动作，不使用没有业务含义的占位词。
- 按钮是否可用必须由业务条件决定；不可执行时使用组件已有 `dis` 状态，不通过降低透明度手工模拟。
- 1920 与 1280 页面使用同一组件集。空间不足时应先调整外部操作区排布；不得缩放按钮内部图标、文字或间距。

## Variant

### `类型`

| Pixso 值 | 用途 |
|---|---|
| `一级按钮` | 页面或操作区域的主要动作 |
| `二级按钮` | 次要、取消或辅助动作 |
| `三级图文按钮` | 弱层级的图标加文字动作 |

### `状态`

| Pixso 值 | 使用条件 | 交互说明 |
|---|---|---|
| `nor` | 按钮可用且当前没有指针交互 | 默认可操作状态 |
| `hov` | 指针悬停在可用按钮上 | 指针离开后恢复 `nor` |
| `pre` | 指针按下按钮、动作尚未释放 | 释放后根据业务结果回到 `nor`、进入其他界面状态，或变为 `dis` |
| `dis` | 操作不满足执行条件或暂不可用 | 不响应点击；条件恢复后切回 `nor` |

## 已读取结构

- `一级按钮`：高度 32，宽度为 `fit_content`；内部包含 16 × 16 图标区域和文字区域。
- `二级按钮`：高度 32，宽度为 `fit_content`；内部包含图标、文字及组件原有的附加区域。
- `三级图文按钮`：宽高为 `fit_content`；内部包含 16 × 16 图标区域和文字区域。
- 当前示例文字节点尺寸为 56 × 20；它是 Pixso 组件中的当前内容表现，不代表所有业务文案必须固定为该宽度。

## 允许修改

- 切换 `类型` 和 `状态` 的已有值。
- 修改组件对实例开放的按钮文字或图标内容。
- 调整组件实例在父容器中的位置、对齐方式和外部布局。
- 在组件自身约束允许的范围内由内容驱动宽度。

## 禁止修改

- 禁止新增 `类型` 或 `状态` 值。
- 禁止把 `nor`、`hov`、`pre`、`dis` 改写成其他命名后用于组件实例。
- 禁止解绑、拆散、扁平化组件实例。
- 禁止增删或重排按钮内部图标、文字和容器图层。
- 禁止手工覆盖组件内部高度、内边距、间距、圆角、颜色、描边、字体、图标尺寸和变量绑定。
- 禁止使用图片、截图、HTML/CSS或基础图层仿制此按钮。
- Pixso 当前组件没有 `loading`、`selected` 或 `focus` Variant；不得在本组件上自行制造这些状态。若业务必须表达这些状态，应改用有对应 Variant 的其他已批准组件，或记录组件缺口。

## 选择与实例化

1. 使用 `read_components` 读取组件集 `按钮`。
2. 使用 `query_nodes` 查询 Component Set ID `221:180916`，并按真实 Variant 名称解析目标组合。
3. 将 `query_nodes` 返回的目标 Variant `guid` 用作实例引用，不得直接把 Component Set ID 当作实例 `ref`。
4. 写入后检查实例仍保持组件关联，并核对 `类型`、`状态` 与业务条件一致。
