# 内容与数据规则

- 只使用用户提供、数据源返回或 Pixso 规范明确给出的内容。
- 规范稿中的姓名、点位、报警、时间、数量、趋势和风险结论均视为示例，不得复制为新业务真实数据。
- 缺少内容时保留组件默认占位或使用“--”“暂无数据”等组件既有空态；不得用看似真实的数据填满页面。
- 正常、加载、空数据、失败、无权限、未配置等状态必须语义分离，不用一张静态图替代。
- Tag 文本最大宽度、报警内容滚动、标题省略与 Tooltip 依 [`layout-responsive.md`](layout-responsive.md) 执行。
- 多语言不得破坏组件：优先使用组件既有响应式、截断、换行或 Tooltip，不改内部字号和间距强行容纳。
- 无真实监控流或监控截图时，按 [`assets/image-resources.md`](assets/image-resources.md) 使用 Pixso“图片资源”中的占位画面，默认优先 `行业背景2`；不得用纯色空底或无关素材代替。
- 图片、视频和地图加载失败时使用对应失败状态；“尚未接入真实数据”与“加载失败”不得混用。
