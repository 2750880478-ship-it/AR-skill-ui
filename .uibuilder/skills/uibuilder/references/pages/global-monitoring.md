# 全域监控

## 目标与结构

用于汇总风险概览、报警事件、违规人员、异常点位和趋势分析，并通过地图或高点进入单高点 AR 实景。参考 Pixso“全域监控设计方案&说明-黄蓝红”及 `1404:401373` 适配规则。

结构顺序：全域实景/地图 → 数据概览 → 报警记录 → 高频违规人员/异常点位 → 趋势或报表。正在报警的高点可进入单高点界面。

## 必用组件

- `数据概览`
- `报警记录`、`alarm card`
- `高频违规人员卡片`、`高违规人员`、`违规人员详情`
- `趋势`及现有条形图、曲线图、环形图组件
- 地图与高点组件按 [`map-configuration.md`](map-configuration.md) 和 [`high-point-patrol.md`](high-point-patrol.md) 使用

名称、ID、Variant 与状态见 [`../components/index.md`](../components/index.md)。

## 状态与适配

- 覆盖正常、全局加载、局部加载、骨架、图片失败、数据失败和空数据。
- 覆盖未配置高点、未配置地图、相机未配置位置信息。
- 黄色、青色、红色通过全局主题变量切换；不复制一套局部硬编码样式。
- 1920 与 1280 信息语义一致，按规范改变列数、卡片排布和密度。标题空间不足时先压缩操作文字，再隐藏操作文字，最后截断标题并提供 Tooltip。

## 验收

确认主题统一、两尺寸入口一致、加载范围正确、空态与失败态可区分、地图/高点跳转明确，且未把规范稿示例统计作为真实数据。
