# 系统配置

## 范围

- 资源标签配置：将监控点和高点添加到全景图，详见 [`tag-configuration.md`](tag-configuration.md)。
- 视频播放配置：码流、抓图和录像存储路径等基础设置。
- 皮肤配置：选择黄色、青色或红色主题。
- 叠加信息显示配置：选择沉浸、均衡或易读等视效，调整报表、报警和标签等面板的整体可读性。

## 必用组件与变量

使用 `配置`、`皮肤配置`、`透明度配置`及 Pixso 中对应表单组件。主题和视效必须切换页面级变量模式；组件继续绑定原变量，不逐项改色、透明度或阴影。

## 规则与状态

- 同一 Frame 只能有一个主题模式和一个视效模式，主题/视效对比测试稿除外。
- 同一业务的 1920 与 1280 默认使用相同变量模式。
- 配置项覆盖默认、悬停、选中、禁用、保存中、保存成功和保存失败中实际存在的组件状态。
- 未保存离开、破坏性重置或删除按现有确认组件处理；不得自行创造交互。

## 验收

切换主题和视效后检查整页组件同步响应、变量绑定未解除、语义色正确、两尺寸一致；视频与路径设置检查错误提示、保存反馈和长文本处理。
