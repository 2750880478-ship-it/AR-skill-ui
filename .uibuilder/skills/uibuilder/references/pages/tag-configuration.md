# Tag 与资源标签配置

## 目标与结构

用于维护标签组，从场景或资源中选择标签，并将 Tag 放置到全景图后编辑。画布态与配置态均须复用现有 Tag 组件。

## 必用组件

- `图上Tag/组合`、`Tag编辑`、`添加标签`
- `标签选择`、`标签过滤`、`多选标签`
- `搜索标签`、`搜索标签-选中标签`
- 对应业务的文本、图文、时间、颜色、相似度、车牌、体温、配速、进出状态和门锁状态标签

组件变体与状态见 [`../components/index.md`](../components/index.md)。

## 必须流程

1. 打开配置引导，添加标签或标签组。
2. 选择标签组和资源类型；支持场景列表、场景图片、资源全部、资源列表、资源图片模式。
3. 点击菜单项或图片进入放置状态，鼠标表现为标签。
4. 点击画面固定 Tag，并打开 `Tag编辑`。
5. 编辑面板距左侧 ≥328px 时放目标左侧，否则放右侧，且不得越界。
6. 删除已使用标签组必须二次确认，并说明组内标签会同步删除。

## 状态与验收

按具体组件覆盖默认、悬停、按下、选中、报警和编辑。单个布防标签通常位于左上；多个标签按规范分角放置。验证搜索/过滤/选中、放置、编辑、删除确认、超长文字 Tooltip，以及 1920/1280 面板位置。
