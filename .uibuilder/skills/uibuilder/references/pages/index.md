# AR 页面目录

先匹配最接近的页面类型，再读取该页引用的组件文档。页面名沿用“AR实景设计规范11”的业务命名。

| 页面 | 适用任务 |
|---|---|
| [AR 实景监控](ar-live-monitoring.md) | 实时全景视频、图上 Tag、报警叠加、画面操作 |
| [全域监控](global-monitoring.md) | 风险总览、高点地图、报警/违规/异常点位与趋势 |
| [报警分析](alarm-analysis.md) | 报警统计、报表、记录、详情与筛选 |
| [点位事件](point-events.md) | 普通监控点、门设备、出入口、雷达、广播、人车事件 |
| [高点与轮巡](high-point-patrol.md) | 高点选择、轮巡计划、预置点、相机通道 |
| [Tag 与资源标签配置](tag-configuration.md) | 标签组、资源选择、图上放置与编辑 |
| [地图配置](map-configuration.md) | 地图、高点位置、画面范围与未配置状态 |
| [系统配置](system-configuration.md) | 皮肤、视效、视频播放与叠加信息配置 |

页面文档定义页面级组合规则；控件的 Variant、状态和细节始终以 [`../components/index.md`](../components/index.md) 中对应组件 MD 为准。
