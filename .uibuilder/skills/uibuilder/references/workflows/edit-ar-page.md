# 编辑 AR 页面

1. 用 `fetch_context` 确认目标 Page、Frame 和选区，用节点 ID 锁定修改范围。
2. 读取目标节点、相邻层级、组件实例、变量绑定和当前 Variant；先确认现状再修改。
3. 对照对应 [`../pages/`](../pages/index.md) 页面规范与组件 MD，列出“保留、修改、新增、删除”项。
4. 仅修改任务涉及的实例属性、暴露内容、外部布局或变量模式；保留无关结构和交互。
5. 禁止 detach、重画、增删组件内部图层或用固定视觉值覆盖变量。
6. 若一张尺寸发生业务变化，同步检查另一张适配稿；布局可不同，信息和能力必须一致。
7. 截图前后对比，确认没有引入遮挡、越界、状态丢失、变量解绑或无关改动。

用户要求删除已有业务模块时，只删除已精确确认的目标节点，并在交付中说明影响。
