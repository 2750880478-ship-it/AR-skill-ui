# 监控画面图片资源

## 何时读取

创建或编辑 AR 实景页面、全域监控页面，且没有真实监控视频、用户截图或明确业务图片时读取本文件。

## 来源与优先级

图片必须来自 Pixso“产品组件”页面中的“图片资源”区域。按以下顺序选择：

1. 用户明确指定的图片资源。
2. 与业务现场最匹配的现有行业背景。
3. 未指定场景时默认使用 `行业背景2`（外层组件 `251:59238`，图片图层 `434:111709`，1920×1080）。
4. `行业背景1` 仅在场景语义更匹配或用户明确指定时使用；不得因为检索顺序更靠前而优先选择。

具体节点结构与约束见 [`../components/other/行业背景2-251-59238.md`](../components/other/行业背景2-251-59238.md)。

## 布局规则

- 图片资源属于“真实场景层”，始终置于页面底层。
- 优先使用外层组件。若实例或跨页克隆只显示白色 Frame，使用 Pixso Plugin API 对资源图片图层执行 `exportAsync()`，再通过 `pixso.createImage()` 将同一资源写入目标矩形；这是 Pixso 内部资源迁移，不得换成外部图片。
- 覆盖监控视窗并按比例裁切铺满，不拉伸、不平铺、不留纯色边。
- 1920 与 1280 分别调整裁切区域，不能整体等比缩放整个页面。
- 保留能表达场景的主要建筑、道路或设备区域，并为面板、Tag 和报警叠加保留可读背景。
- 图片仅是设计阶段占位资源，不作为真实地点、设备、报警或时间的依据。

## 避免重复内容

`行业背景2` 组件可能包含示例点位或 Tag。优先复制使用该资源的完整规范 Frame；若单独实例化后页面已有同类叠加信息，需选择不重复的参考结构，不能通过拆散组件或隐藏内部图层来修补。

## 验收

- 画面可见且无黑底、透明露底、拉伸或异常裁切。
- 图片资源来源可追溯到 Pixso 组件 ID。
- 页面内容仍按实景层、业务信息层、交互操作层排列。
- 没有把占位图内容写成真实业务信息。
