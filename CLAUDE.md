# AR UIbuilder Project Instructions

Before any Pixso design creation, edit, update, or restoration task for AR scene monitoring, global monitoring, alarms, point events, maps, high-point cameras, patrol plans, or related configuration:

1. Read `.uibuilder/rules/force-uibuilder.md`.
2. Read `.uibuilder/skills/uibuilder/SKILL.md` and only the references routed by that skill.
3. Treat the open “AR实景设计规范11” Pixso file as the design source of truth.
4. Reuse real Pixso component instances, variables, styles, variants, and reference frames. Do not redraw existing components or hardcode available tokens.
5. Preserve the AR three-layer model: real scene, business information, interaction controls.
6. Validate 1920/1280 adaptation, theme, visual-effect mode, interaction states, loading/empty/error states, and alarm emphasis with screenshots before delivery.
